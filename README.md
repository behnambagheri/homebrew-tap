# bea.sh Homebrew tap

Project-maintained Homebrew packages from [behnambagheri](https://github.com/behnambagheri).

## IPinfo

The native IPinfo app and its Homebrew cask have been retired.
Use the [IPinfo web app](https://ip.bea.sh) and choose **Install app** in the
footer to install the PWA. On Mac Safari, choose **File → Add to Dock**.

To remove an existing cask installation:

```sh
brew uninstall --cask ipinfo
```

[IPinfo project and PWA instructions](https://github.com/behnambagheri/ipinfo)
